# أرشيف شؤون المعلمين — مدرسة أم المؤمنين

مشروع مستقل تمامًا، فيه ملف HTML واحد `index.html` (CSS+JavaScript بداخله)، وخادم `app.py`، و`requirements.txt`، وملف إعداد قاعدة البيانات `schema.sql`.

## 1) GitHub من الهاتف
1. أنشئ **Private** repository باسم `umm-school-archive-2026`.
2. بعد فتح المستودع اضغط **Add file → Upload files**.
3. استخرج محتويات ZIP المرفق، وارفع الملفات **الأربعة نفسها إلى جذر المستودع** (بدون رفع مجلد خارجي):
   - `app.py`
   - `index.html`
   - `schema.sql`
   - `requirements.txt`
   - يمكن إضافة `README.md` إن رغبت.
4. اضغط **Commit changes**. على الهاتف إن اختفى الزر، فعّل "موقع سطح المكتب" من متصفح Chrome.

## 2) Supabase جديد تمامًا
1. افتح https://supabase.com/dashboard وأنشئ **New project** باسم `umm-school-archive-db`.
2. افتح **SQL Editor → New query** والصق محتويات `schema.sql` ثم اضغط **Run**.
3. افتح **Storage**: يجب أن يظهر مخزن `teacher-archive-private` وأن يكون **Private**.
4. افتح **Project Settings → API Keys** (مكان القوائم قد يختلف)، واستخرج رابط المشروع ومفتاح server secret/service_role. **لا تشارك المفتاح مع أحد، ولا تضعه في GitHub أو HTML.**

## 3) Render جديد تمامًا
1. https://dashboard.render.com → New → Web Service.
2. اربطه بمستودع `umm-school-archive-2026` الجديد.
3. Name: `umm-school-archive-web`
4. Language: Python 3
5. Build Command: `pip install -r requirements.txt`
6. Start Command: `gunicorn app:app --workers 1 --threads 4 --timeout 180`
7. اختر الخطة الملائمة. على الخطة المجانية قد يتأخر بدء الخدمة بعد الخمول.
8. في Environment أضف **هذه المتغيرات الخمسة** (كلها خاصة بالخادم):
   - `SUPABASE_URL` = عنوان مشروع Supabase الجديد `https://xxxx.supabase.co`
   - `SUPABASE_SERVICE_ROLE_KEY` = مفتاح secret أو service_role الجديد
   - `FLASK_SECRET_KEY` = سلسلة عشوائية قوية من 40 حرفًا أو أكثر
   - `FIRST_ADMIN_USERNAME` = اسم الدخول الأول (مثال: `adminschool`)
   - `FIRST_ADMIN_PASSWORD` = كلمة مرور قوية من 12 خانة على الأقل
9. احفظ المتغيرات وأعد نشر الخدمة.
10. افتح عنوان Render. عند أول تسجيل دخول ينشئ الخادم حساب المدير الأول إن كانت قاعدة المستخدمين فارغة.
11. ادخل إلى قسم المستخدمين وأنشئ حسابات للتصوير، كل حساب بصلاحياته.

> مهم: تجنّب استخدام مفاتيح أو كلمات مرور أي منظومة سابقة. لا تغير `gtech-attendance` أو `umm-al-mumineen-school` أو مشروع وثائق شؤون المعلمين السابق.

## 4) إضافة 400 معلم مرة واحدة
أنشئ ملف Excel `.xlsx` بأعمدة:

| الاسم | الرقم الوطني | الوظيفة |
|---|---|---|
| أحمد محمد علي | 123456789012 | معلم |

استيراد الأسماء من قسم **المعلمون والأرشيف → استيراد Excel**. إذا تطابق الرقم الوطني مع معلم موجود، تتحدث بياناته دون حذف مستنداته.

## 5) طريقة التصوير والأرشفة
- افتح اسم المعلم، ثم اختر نوع المستند من الخانات الخمس.
- زر **تصوير** يفتح كاميرا الهاتف، وزر **صور متعددة** يتيح اختيار صفحات من المعرض.
- راجع الصور، دوّر أو احذف غير الواضح، ثم اضغط **تحسين وتحويل إلى PDF وحفظ**.
- النظام يحاول كشف الورقة وقص حدودها تلقائيًا؛ ويضبط التباين ويصدرها كصفحة A4. **لا يمكنه استعادة كتابة ممسوحة أو غير مقروءة**، ولا يضمن اكتشاف حدود كل صورة.
- لزيادة صفحات وثيقة موجودة استخدم **إضافة صفحة**. لتصحيح صفحة موجودة استخدم **استبدال صفحة** (يطلب رقم الصفحة).
- المسؤول يستطيع حذف صفحة أو PDF كاملًا، أو حذف المعلم وكل مستنداته.
- خيار **تنزيل PDF كامل** يجمع المسوغات المتوفرة في ملف واحد، و**مجلد المعلم ZIP** ينزل ملفات PDF الخمسة منفصلة داخل مجلد باسم المعلم.
- من **التصدير** يمكن تنزيل دفعات 20 أو 50 أو 100 أو حتى 400 معلم. يُفضّل دفعات صغيرة لهواتف Android.

## تنبيهات الخصوصية والأمان
- المرفقات تتضمن بيانات شخصية حساسة مثل الرقم الوطني وشهادة الميلاد. اجعل المستودع **خاصًا**، ومخزن Supabase **خاصًا**، وحسابات المستخدمين بكلمات مرور قوية.
- الملف ZIP ينزل إلى **تنزيلات الهاتف**، ولا يستطيع متصفح الويب إنشاء مجلدات مباشرة دون إذنك. استخرج ملف ZIP لتظهر مجلدات المعلمين.
- توثيق الدخول عن طريق جلسة خادم وكلمات مرور hashed؛ يُمنع الوصول المباشر للجداول والمخزن بمفاتيح العميل. ضَع مفتاح Supabase السري في **Render Environment فقط**.
- هذه نسخة تشغيل أولية: **اختبرها على بيانات تجريبية أولًا**، ولا تعتمدها كمخزن وحيد لأوراق 400 معلم قبل اختبار الصلاحيات، واسترجاع نسخة احتياطية فعلية من قاعدة البيانات وStorage، وسعة وتكلفة المشروع.
- لتغيير كلمة مرور المدير الأولى بعد التشغيل، استخدم قسم المستخدمين (لا تعتمد على متغير البيئة لتغييرها بعد الإنشاء).
